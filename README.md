# 🏥 Coding-Lab_Group15: Kenyatta National Hospital System

A bash-scripted system to manage and analyze simulated patient logs safely.

---

## 🛠️ Script 1: Hospital Administration (`hospital_admin.sh`)

### 🧱 System Initialization (Member 1 - Architect)
The `initialize_system()` function checks your directory structure before data processing starts:
* **`active_logs/`** - Created if missing; stores live incoming patient sensor logs.
* **`archived_logs/`** - Created if missing; holds older rotated history logs.
* **`reports/`** - Created if missing; holds generated data analysis files.

### 🚀 How to Run It:
```bash
chmod +x hospital_admin.sh
./hospital_admin.sh
```
